# Traceform Agent OS 0.6.15

本版本把「数据能不能真的同步起来」这件事做实了，并补齐了深色、审计与发布验证。

## 本次重点

### 系统入口

- 长按图标有三个快捷方式：**审计日志**、**任务中心**（新增）、**新建任务**；
- 「新建任务」会滚到输入框、聚焦并直接弹出键盘；
- 三个快捷方式都经由主界面转发，因为它们指向的页面不对外开放（`exported=false`），避免其他应用直接调起。



### 同步（此前是断的，这版修好）

- **修复：新建记忆从不写入版本记录**，导致同步显示“完成”但一条数据都没搬过去。现在 `createMemory` 在同一事务里写入向量时钟版本。
- **修复：历史记忆升级后无法同步**。schema 11 增加回填迁移，给旧记忆补上版本；迁移里递归取库的问题也一并修了（否则迁移会静默失败）。
- **冲突不再静默覆盖**：远端与本机同时修改时保留双方版本，生成待定项；用户可查看、选择、并在两种版本之间来回切换。
- **后台同步**：周期任务可选 15 分钟 / 1 小时 / 6 小时，默认关闭；配对成功后记住对端地址，并显示每台设备上次同步的时间与结果。

### 端侧模型

- 支持 GBNF 约束解码：JSON 结构不再依赖模型自觉。
- 生成 → 校验 → 修复：把校验失败的具体原因写回提示再生成，内容通过率从 5/10 提升到 10/10（同一组 10 条用例、grammar + 512 token）。
- 输出上限从 128 放开到 512 token（上下文 2048）。
- 双模型可选：Qwen2.5-1.5B（快）与 MiniCPM5-2B（更强）。

### 审计与知情

- 审计日志：只读列表、导出 TSV（导出前显示条数与时间范围）。
- 诊断导出：先显示将写入的字段清单与崩溃摘要，确认后才选保存位置；崩溃只保存在本机，不自动上传。
- 加密档案导出前显示将包含的记忆/任务/删除标记条数。

### 界面

- 深色模式覆盖主屏、设置、审计、任务中心、模型页，以及全部弹窗（含输入框）。
- 文案统一走双语目录；新增缺键、占位符数量、中文硬编码三道静态检查。
- 静态快捷方式：长按图标可直达「审计日志」「新建任务」。

## 安装与升级

1. 本包为侧载分发，安装时需要允许“未知来源”。
2. **升级后不可回退**：数据库 schema 只升不降。回退到旧版本前请先导出加密档案。
3. 安装前可核对签名指纹（应与下方一致）：
   `9effee32f57b35c256529e97cd8db435813e84025d48601c00770b6adf95a6db`
4. 校验和见 `SHA256SUMS`；`build_report.json` 与 `release_verification.json` 是本次构建的可信来源。

## 已知限制

- **跨两台真机的同步尚未验证**；同机双包端到端已完成（含带数据同步与冲突处理）。
- 真实局域网对端未验证，目前只验证了本机回环。
- 端侧模型输出受 token 上限约束，长文稿会被截断。
- 自动同步的功耗影响尚未测量。
- 应用商店分发未接入；本版仅通过 GitHub Releases 提供。
