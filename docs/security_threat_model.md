# 威胁模型与审计准备（E3）

状态：**草案完成，等待外部审计方**。本文件用于界定资产、对手、信任边界与首轮审计范围；它不是审计报告，也不构成安全保证。

## 1. 系统概览与信任边界

| 组件 | 位置 | 信任边界 |
|---|---|---|
| 加密档案（导入/导出） | 应用私有目录 + 用户选择的位置 | 用户口令是唯一密钥来源 |
| 跨设备同步 | 本机 Rust 传输 + 回环/局域网 | 配对记录 + Keystore 绑定 |
| 设备身份 | Android Keystore P-256 | 私钥不可导出 |
| 端侧模型 | 打包的 llama.cpp 运行库 + 用户导入的 GGUF | 模型文件由用户提供并校验 SHA-256 |
| Traceweave Provider / Broker | Binder + 签名白名单 + 逐任务授权 | 调用方身份由系统校验 |
| 发布签名 | 本地 keystore + 加密归档 | 见[生产签名决策](production_signing_decision.md) |

## 2. 资产

1. 用户记忆与任务内容（明文仅在设备内存/加密库中出现）。
2. 删除意图（墓碑）与冲突选择结果。
3. 设备身份私钥、配对记录与传输会话密钥。
4. 加密档案口令与恢复密钥。
5. 发布签名私钥。
6. 用户导入的模型文件与推理输出。

## 3. 对手与能力

| 对手 | 能力 | 不在范围内 |
|---|---|---|
| 网络攻击者 | 中间人、重放、篡改、拒绝服务 | 大规模流量分析对抗 |
| 恶意已配对设备 | 伪造记录、复活已删内容、滥发数据 | 供应链投毒 |
| 丢失/被盗设备 | 离线后重入、读取本机数据 | 物理芯片提取 |
| 不可信中继 | 观察密文与元数据 | 服务端明文 |
| 本地恶意应用（无 root） | 通过 Binder 调用、诱导授权 | root/越狱 |
| 备份窃取者 | 获取加密归档 | 获取恢复密钥 |

## 4. 攻击面与现有缓解

| 面 | 威胁 | 现有缓解 | 证据 |
|---|---|---|---|
| 档案加密 | 弱口令、篡改、重放 | AES-GCM + PBKDF2、认证标签、版本与迭代参数校验 | `MemoryArchive`、档案测试 |
| 档案导入 | 复活已删记录、过期审核 | 墓碑优先、事务内重核快照 | [删除审核](../artifacts/agent_os/next_stage/archive_deletion_review_20261030.json) |
| 同步传输 | 未配对接入、重放、超限 | 允许列表、Noise、帧/会话预算、绑定签名 | [C6 收据](../artifacts/agent_os/next_stage/sync_e2e_scenario_20261031.json) |
| 配对 | 伪造设备、错码 | 双方指纹 + 6 位确认码、撤销即拒 | [配对](../artifacts/agent_os/next_stage/sync_pairing_20261031.json) |
| 合并 | 删除复活、时钟伪造 | 墓碑优先、32 设备上限、同钟不同内容拒绝 | [合并](../artifacts/agent_os/next_stage/memory_merge_device_20261030.json) |
| 模型运行 | 恶意 GGUF、越界输入 | SHA-256 校验、输入/上下文上限、取消 | [质量](../artifacts/agent_os/next_stage/local_model_quality50_20261031.json) |
| Provider/Broker | 越权读取、权限继承 | 签名白名单 + 包名/UID 校验 + 逐任务授权 | Traceweave 记录 |
| 签名 | 私钥泄露、误签 | 恢复演练、发布校验、开发密钥标注 | [E1](production_signing_decision.md) |

## 5. 已知残留风险

1. 同步节点身份目前用固定合成种子，尚未接入配对记录——**不可用于真实数据**。
2. 撤销不会主动切断空闲会话，只在下一个请求拒绝。
3. 没有协议回执与 manifest 差异；全量交换可能被滥用做资源消耗。
4. 模型输出格式不稳定（50 题中严格 JSON 0/10），必须经过校验层。
5. 开发签名证书不具备生产含义；恢复密钥丢失即无法更新。
6. 未做独立审计；本项目自己的验收不能替代第三方结论。

## 6. 首轮审计范围建议

**范围 A：同步与身份（优先级最高）**
- Rust 传输、绑定转录、配对码派生、允许列表、会话上限；
- 与 Android Keystore 的 JNI 边界；
- 撤销与重入语义。

**范围 B：档案与合并**
- 加密格式、口令派生、导入事务与墓碑语义；
- 合并规则的并发与重放边界。

**范围 C：Provider/Broker 与模型集成**
- 签名白名单、包名/UID 校验、授权生命周期；
- 模型文件校验与输入边界。

**不在首轮**：UI 可用性、性能、功耗、商店分发流程。
