# 环境感知、记忆与工作流边界

## 环境感知

仅在用户启用感知时读取本机传感器。运动状态采用最多三秒、有限样本的加速度计与陀螺仪窗口，样本不足或超时为未知；稳定后只区分低运动与检测到运动，不推断走路、跑步等活动。会话结束清除窗口。只有两种稳定状态之间的变化才形成一次内存中的观察事件，来源、方法和时间可供审核，不保存原始传感器流。传感器停用或数据缺失不能被解释为静止。

用户可审核最近一次观察、编辑文字并明确确认后保存为记忆；默认有效期七天，也可以选择三十天或无有效期。感知不会自行写记忆或发送云端。窗口和事件的模拟序列已做隔离真机验证；真实光照回调可用不等于所有真实运动场景的识别精度已经验证。

## 用户记忆

记忆可编辑并设置有效期；到期后不再出现在新任务的可选记忆中，但保留在记忆库中供查看、续期、导出或删除。到期判断使用设备墙上时钟，时钟变化会影响判断。按来源删除会先展示范围并确认；保存后发生变化的记录会导致整批删除被拒绝。删除记忆不追溯删除此前任务快照、已生成文件或历史档案。

档案 schema 6 保存有效期和用户编辑标记。新版可读取旧版档案，旧版不能读取 schema 6：跨设备迁移前须先把目标设备升级到 0.6.0 或更高版本。档案不转移 Android 文件授权、云端密钥或单次授权。测试使用旧版隔离包导出合成档案，再在独立安装身份导入；生产数据不参与该测试。

## 文稿与日历

文稿必须在当前设备完成文件写入与读回核验，用户才能继续创建关联日历草稿。日历是独立任务，不继承文稿文件权限、所选记忆或云端授权；每次外部交接仍需独立确认。重复进入返回同一个关联任务，进程停止后也不自动重复交接。日历应用的返回不能证明事件已保存；交接后状态为结果未知，用户应在日历应用核对。本功能是固定的两步链路，并非任意多步工作流引擎。

## 云端请求

预览包含完整请求、字节数和用户选择的输出 token 限额；限额包含在单次授权的请求正文内。此限额不限制输入 token 或金额，也不能保证服务商遵守，服务商必须支持 `max_tokens`。实际费用取决于服务商计价和用量，本功能不宣称设定了金额硬上限。

失败按本地类别显示，不显示服务商错误正文或密钥。超时可能发生在服务商已经处理请求之后；不自动重试。用户可重新审核新的完整请求并单独授权，或改用本地规划。文稿和通用规划都拒绝明确标记为截断的回复及工具调用；通用规划对未提供完成原因的兼容接口仍无法判断其是否截断。验证使用本机回环模拟服务，不调用用户的真实模型端点。
