# 环境感知固定读数修复（0.5.2）

## 原因

普通 APK 没有加载原生库时，Java 降级分支固定返回 Stationary / IndoorLighting，未携带采样值；主屏点击和卡片又分别用 150 Lux / 31.5°C 补缺省值。胶囊也将“静止、口袋保护生效”写成固定文字。刷新只是再次渲染这些值。

## 修正

- 原生库缺席时保留 Android 回调的光照、接近、IMU 与系统电池温度，使用明确标注的保守运动规则；不宣称识别走路、跑步、乘车或桌面放置。
- 未收到、不可用或停用的数据保持未知，不生成数字。IMU 超过五秒没有新样本则无效；光照/接近按 on-change 传感器语义在同次注册期间缓存，显示光照样本年龄，重新启停清空旧会话。
- 主屏显式启用后每秒刷新，退到后台停止并清理定时器。胶囊展开时显示同一上下文，不单独开启传感器，不再宣称口袋保护已生效。
- 温度显示为“电池温度”。不新增后台采集、云请求、记忆写入或权限。

## 验证

[修复前失败](../artifacts/agent_os/sensors/disabled_context_red.json)确认停用采集却报告静止。[修复后测试](../artifacts/agent_os/sensors/final_checks.json)包含十项感知检查、四项工作流保护和十项任务中心检查。实际 Pixel 隔离包收到光感回调；合成输入验证零 Lux、数值变化、运动变化、遮挡规则和未知值显示。实际遮挡/移动变化不由合成用例冒充。

[启停验收](../artifacts/agent_os/sensors/opt_in.json)保持显式启停边界。生产候选通过现有十四项宿主测试与同签名发布门禁。正式安装和主屏、后台生命周期验收另见[设备收据](../artifacts/agent_os/sensors/device_installation.json)。本轮没有重跑此前二十八组完整功能回归或二十分钟耗电试验。

来源与范围：本地实时读数不持久化，不导出个人遥测；归档及数据库格式不变。原生矢量图标沿用 0.5.1，0.5.2 修复感知显示及降级逻辑。
